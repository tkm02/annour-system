### Résumé — verdict : ⚠️ OK avec réserves
Le workflow CI est sûr (jeton en lecture seule, aucune expression `${{ }}` contrôlable, gitleaks vérifié par somme de
contrôle), de même que le hook et le lockfile. Un 🟠 introduit : `.claude/settings.json` autorise sans confirmation
`git branch:*` (suppression forcée de branches). Existant : repli sur l'API de production (🟠, nouveau), compte
désactivé non déconnecté (🟡, nouveau) ; `next` vulnérable et JWT/CSP restent ouverts (F-S1, F-S3).

### Points positifs
- 401 avec jeton : `logout()` et retour à `/` sans boucle ; aucun jeton journalisé ; erreurs sans trace interne
  (`request_id` pour les 5xx).
- Zones sensibles : aucun `dangerouslySetInnerHTML`, `innerHTML`, `window.open` ni lien construit à partir de données.
- Menus par rôle présentés comme du confort, alignés sur les gardes `Require*`.
- Jeton de reçu gardé en mémoire uniquement ; PDF santé uniquement via l'export tracé.
