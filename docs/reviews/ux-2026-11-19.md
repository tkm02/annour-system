### Résumé + verdict : ⚠️ OK avec réserves
Les écrans récents (finance, santé, membres CO, visiteurs) s'appuient bien sur les tokens et les composants communs
(états, confirmations, `Field`). Défauts transverses sérieux : focus clavier presque invisible partout (≈ 1,1:1) ;
texte blanc sur vert ou gris clair (1,8 à 3,2:1) ; modales d'accès faites à la main, sans sémantique de dialogue ;
champs dont le seul libellé est le placeholder (dont deux champs médicaux) ; retours trompeurs (tableau de bord à 0 en
cas d'erreur, ajouts de badges perdus au rechargement, compte désactivé sans confirmation). Audit de référence : tous
les constats sont préexistants et non bloquants pour une PR ; les 🟠 doivent être planifiés.
